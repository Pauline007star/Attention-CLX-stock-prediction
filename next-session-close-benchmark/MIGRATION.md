# 改进版如何回答预测问题

新版项目名为 **Next-Session Close Forecasting**，研究问题是 **Do Market Features Beat the Last Close?** 每个交易日收盘后，面对下一交易日的收盘价预测，有两个要分别验证的问题。第一，加入市场因子和 ARIMA 残差，能不能让同一个 LSTM 的误差下降？第二，误差下降以后，模型是否值得替代直接沿用前收盘价的做法？

在相同的 180 个测试日上，加两个 PCA 分量的 LSTM 平均 MAE 比同结构的行情版低 **1.49%**，但比前收盘价高 **4.76%**。因此，这组实验观察到了特征带来的模型内改善，同时支持继续把前收盘价作为该时段的基准。完整指标及三次运行记录见 [实验结果](results/RESULTS.md)。

改进版是独立副本。结果属于新版统一评估协议，旧仓库的源码、实验和原始记录仍保存在原处。

## 为了让比较成立，具体改了什么

| 原项目问题 | 本版处理 |
|---|---|
| ARIMA 残差来自全样本模型 | 在最初 252 日估计一次参数，此后用单步预测误差形成滞后特征 |
| XGBoost 可以读取目标日字段 | 树只接收预测日前的六期窗口，使用可复现的固定参数 ARIMA 作为待校正基线 |
| 缩放和 PCA 范围不一致 | 六个重新计算的因子先用训练段做标准化和 PCA。循环网络输入及目标转换也只拟合训练数据 |
| 混合模型输出、PCA 向量和收盘价混在一起 | 全部结果统一为下一交易日收盘价。PCA 进入 LSTM 输入。Attention 主干单独评估 |
| 测试段用于验证，价格按位置合并 | 用独立验证段选神经 checkpoint 与树数量，统一日期索引，并输出预测时点 |
| 运行目录、环境和写入行为无法追溯 | 一个命令入口、固定直接依赖版本、新运行目录、数据哈希、配置和结果文件 |

为方便在当前 Apple Silicon 环境跑通，Attention 主干从 Keras 移植到 PyTorch。它保留 Conv1D、双向 LSTM、时间注意力及 sigmoid 输出拓扑。用于消融的小型 LSTM 有意用统一的 24 单元模型预测收盘价差，再还原为价格数值。ARIMA 残差树已完成，但原 Attention-to-XGBoost 混合路线需要独立的整合与校准协议。

## 如何说明个人贡献

公开 fork 的提交可追溯到原有 LSTM/BiLSTM 训练改动、行情与残差对照脚本，以及 PCA 实验入口和数据表。新版是在本次协作中整理与重跑的，公开链接仍指向旧版。介绍项目时可以先讲原有实验扩展，再说明新版如何让各组模型在相同目标、预测时点和日期下比较。Attention 架构归于上游作者。 [公开 fork](https://github.com/Pauline007star/Attention-CLX-stock-prediction) · [上游实现](https://github.com/zshicode/Attention-CLX-stock-prediction)
